Every page opened, form sent, rule run and status changed on this website, written down as it happens. Create a free account to read it all.

Learning model: accounts and logs are kept in this browser's localStorage, so anyone who can open the browser's developer tools can read them. A real system keeps both on a server. The log is append-only (no delete button) and never records passwords or message text. All data is fake.

  • Filter by part of the site, level or time, and search every line
  • Charts of events by source and per hour, updated live
  • Export the log as CSV or JSON

Use a made-up passphrase of 12 or more characters, such as three random words. Wrong guesses are rate-limited in this browser. Your password is hashed in the browser (PBKDF2 with Web Crypto) and never stored as text.
