Staff access

Sign in with a password and a one-time code. IT can add joiners and mark leavers.

This is a learning model, not a real security system. Everything runs in your browser and is saved in localStorage, so anyone using this browser can read or change it. Real systems check passwords, one-time codes and permissions on a server. All names and passwords here are fake. Never type a real password.
