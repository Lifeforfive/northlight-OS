PC & network tools

Two small read-only scripts for the affected PC. A web page cannot run them, so run them in a terminal with Node.js installed, from the folder that contains tools. They only read information and never change a setting.

Network doctor

Checks the router, then 1.1.1.1, then a website name. Prints PASS or FAIL for each and names the first failing step.

node tools/network-doctor.js

Optional: add a website name, for example node tools/network-doctor.js northlight.example. View source

PC health report

Shows the operating system, free disk space, firewall status and whether updates are current, as PASS or FAIL.

node tools/health-report.js
